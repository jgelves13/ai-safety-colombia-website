### Forbidden anywhere

- Emoji in headlines.
- Faces of un-verified people / AI-generated portraits.

## 3. Content Pillars

Four evergreen lines that anything we post should belong to. If a draft doesn't fit one of these, it probably shouldn't ship.

| Pillar | What | Maps to Figma template |
|---|---|---|
| **Field** | "What is AI safety?" explainers, subfield maps (alignment / governance / evaluation / security) | IG: Quote card • LinkedIn: Carousel "What is AI safety?" |
| **Voices** | Researchers / professionals from LATAM and the Colombian community, with verified bios | IG: Quote card with credit • LinkedIn: Single (speaker reveal) |
| **Resources** | Books, papers, courses worth reading (curated subset of `/recursos/`) | IG: Resource highlight |
| **Upcoming** | Events, hackathon, discussion-group calls | IG: Event announcement / hackathon countdown • Stories: Save-the-date • LinkedIn: Single |

**Mix rule of thumb:** in a steady-state week, post in roughly this ratio across IG + LinkedIn combined — 1 Field, 1 Voices, 1 Resources, 1 Upcoming. During an active campaign (e.g., hackathon), the ratio shifts heavily to Upcoming for ~4 weeks then returns to balanced.

## 4. Cadence

Realistic given Jose is sole author. Don't over-promise volume.

| Channel | Steady state | During hackathon campaign |
|---|---|---|
| Instagram feed | 1–2 posts / week | 2–3 / week |
| Instagram stories | When there's something to react to (events, registrations, drops) | Daily during week-of |
| LinkedIn | 1 post / week | 2 / week |
| WhatsApp status | Event days and registration closes only | 3–4 over the 4-week ramp |
| Print | Only for hackathon and university partnerships | A4 in W-4 + A3 in W-2 |

**Best windows (Colombia, COT):**
- IG feed: Tue / Thu / Sat between 18:00–21:00.
- LinkedIn: Tue / Wed 09:00–11:00 (business-hours scroll).
- WhatsApp status: 19:00–21:00 (when the group is most active).

**Drift discipline:** if a week slips, skip rather than batch-post. Two posts in the same day looks like noise, not effort.

## 5. Bilingual Policy

- **Default locale: Spanish.** AISC's primary audience is Colombian and LATAM.
- **English versions:** ship for hackathon assets (international audience reaches Apart channels) and for LinkedIn single posts (recruiter / researcher reach). EN is a translation, not a rewrite — same image, swapped copy.
- **WhatsApp status:** ES only. The group is Spanish-speaking.
- **Print:** ES only unless the venue is explicitly bilingual (Uniandes English-Track boards, for example).
- **Voice consistency:** apply the [§6 Voice & Copy Rules](./BRAND.md#6-voice--copy-rules) of `BRAND.md` to **both** locales. Don't relax register in EN; don't translate technical terms that should stay English.

### 6.5 AISSA caption pattern

Every campaign in `scripts/flyers/` follows the AISSA Cape Town hub pattern: **the image carries brand and date, the caption carries substance.** Forced by the W-4 launch review: the original assets shipped to master communicated nothing beyond title and URL because every channel was treated as a self-contained poster instead of a feed scroll-stopper plus its caption.

Each PNG holds at most: kicker, title, dates, hub line, hosts row, one decorative motif. Body text on the image stays under ~20 words; ~40% of the canvas is negative space. Anything heavier (hook, project explorations, what Apart brings, judges, CTA) lives in `scripts/flyers/captions/<campaign>.md` as a single file with one section per asset, ES + EN paired. Link strategy is left blank per asset (`[link]`) so the channel owner fills the right URL per post: link-in-bio for IG, full URL for LinkedIn/WhatsApp, link sticker for stories. The A4 poster has no caption channel; substance lives on the printed surface.

Hook follows Apart Research's framing: "AI research that makes systems safe is concentrated in a handful of countries. This weekend is for that." Never invert into savior framing (see `BRAND.md` §6.6). For the current campaign, the reference patterns and lifted phrasing live in `scripts/flyers/.research/PATTERNS.md`.

## 8. File Naming Convention

Every export uses the same name pattern. Drive folder + Figma frame name + filename all agree.

```
aisc-{channel}-{campaign}-{variant}-{locale}.{ext}
```

| Component | Values |
|---|---|
| `channel` | `ig-feed`, `ig-story`, `li-single`, `li-carousel`, `wa-status`, `print-a4`, `print-a5`, `print-a3`, `og` |
| `campaign` | `hackathon-2026-06`, `event-{slug}`, `evergreen-field`, `evergreen-voices`, `evergreen-resources` |
| `variant` | `announce`, `tracks`, `countdown-10`, `judges`, `winners`, etc. — pick a short descriptor |
| `locale` | `es` or `en` (omit for visual-only assets like decorative posters) |
| `ext` | `png`, `jpg`, `pdf` |

**Examples:**
- `aisc-ig-feed-hackathon-2026-06-tracks-es.png`
- `aisc-li-carousel-evergreen-field-what-is-ais-en.pdf`

## 10. Open Graph

Per-route share previews are generated at build time by Satori. The pipeline:

- `src/lib/og.ts` — loads Bricolage / Inter / JetBrains Mono WOFFs, exposes `renderOg(html\`...\`)` returning a 1200×630 PNG.
- `src/pages/og/default.png.ts` — site-wide fallback (cream + forest + tagline).
- `src/pages/og/hackathon.png.ts` — dates + four track pills (forest / coral / sage / yellow).
- `src/pages/og/event/[slug].png.ts` — per event from `src/data/events.json`; type pill colored by event type.
- `src/layouts/BaseLayout.astro` — accepts `ogImage` prop, defaults to `/og/default.png`, writes both `og:image` and `twitter:image`.

To add a contextual image for a new route: create an endpoint under `src/pages/og/`, then pass `ogImage="/og/your-route.png"` to `<BaseLayout>` on the corresponding `.astro` page.

The legacy manual workflow under `scripts/og/` (HTML → headless screenshot → `public/og-image.png`) is deprecated; see [`scripts/og/README.md`](../scripts/og/README.md).

## 11. Measurement (lightweight)

Don't overbuild analytics; track only what changes decisions.

- **Per-campaign:** save IG insights + LinkedIn impressions screenshots into `marketing/{campaign}/metrics.md`.
- **Post-hackathon retro:** which channel drove registrations? (Apart sprint page has UTM `?utm_source=hub-bogota` already set — anything tagged from us shows up there.)
- **What we don't measure:** vanity metrics (follower count growth, individual post likes). Time-cost too high relative to information value for a chapter this size.
